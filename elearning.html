Project Overview & Objectives

E-Learning Web Application merupakan aplikasi web yang dikembangkan untuk mendukung pengelolaan proses pembelajaran antara Admin, Dosen, dan Mahasiswa.

Aplikasi mencakup autentikasi pengguna, pengelolaan profile, manajemen user oleh Admin, manajemen mata kuliah, serta enrollment mahasiswa. Project dikembangkan menggunakan Laravel dengan PostgreSQL sebagai database dan Blade serta Tailwind CSS untuk antarmuka.

Selain pengembangan fitur, project ini digunakan sebagai project personal untuk menerapkan proses software testing, termasuk functional testing, integration testing, UAT, API testing, bug tracking menggunakan Jira, serta automated UI testing menggunakan Selenium 4 dan pytest.

Peran & Tanggung Jawab

Web Development & QA Testing

1
Web Application Development

Mengembangkan fitur aplikasi menggunakan Laravel, termasuk autentikasi, profile, manajemen user, manajemen mata kuliah, dan enrollment mahasiswa.

2
Database & Backend

Mengelola struktur database PostgreSQL, migration, model, controller, serta relasi data yang digunakan oleh fitur aplikasi.

3
Functional & Integration Testing

Melakukan pengujian pada fitur aplikasi menggunakan skenario positif dan negatif serta memeriksa keterhubungan antar fitur dan alur proses.

4
API & Bug Testing

Menguji endpoint API menggunakan Postman, membuat test case, mencatat defect pada Jira, serta melakukan retesting setelah perbaikan.

5
UI Automation Testing

Membuat dan menjalankan automated UI testing menggunakan Selenium 4 dan pytest untuk menguji autentikasi, navigasi course, pembuatan akun, dan logout.

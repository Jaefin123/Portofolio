Gambaran Proyek & Tujuan

Context, methodology, and sanitization notice

Halaman ini merangkum pengalaman dan dokumentasi pengujian software dari project selama magang serta project personal. Pengujian dilakukan untuk memverifikasi fungsi aplikasi, alur antar fitur, validasi API, performa, keamanan dasar, dan automated UI testing.

Proses testing didukung dengan test case, bug report, hasil pengujian, evidence, serta dokumentasi menggunakan Jira dan tools testing yang sesuai dengan kebutuhan project.

Compliance Status
  • Data dan informasi internal telah disanitasi
  • Contoh test case dan defect didokumentasikan
  • Fokus pada proses dan hasil pengujian
  • Beberapa artefak berasal dari project personal

Peran & Tanggung Jawab

QA / Software Tester
  • 1
    Functional & Regression Testing:

    Melakukan manual dan functional testing pada aplikasi web dan mobile, termasuk positive testing, negative testing, dan regression testing setelah perubahan atau perbaikan fitur.

  • 2
    Integration Testing & UAT:

    Menguji alur yang melibatkan beberapa fitur atau bagian sistem serta melakukan UAT berdasarkan role pengguna untuk memastikan proses berjalan sesuai kebutuhan.

  • 3
    Bug Reporting & Defect Verification:

    Membuat bug report berdasarkan expected result dan actual result, melakukan analisis defect, serta melakukan retesting setelah perbaikan.

  • 4
    API Testing:

    Melakukan pengujian API menggunakan Postman dengan memeriksa status code, response body, validasi input, serta skenario positive dan negative.

  • 5
    Performance & Security Testing:

    Melakukan load dan stress testing menggunakan Apache JMeter serta automated security scanning menggunakan OWASP ZAP untuk melihat respons aplikasi dan temuan keamanan dasar.

  • 6
    Automation Testing:

    Membuat dan menjalankan automated UI test menggunakan Selenium 4 dan pytest pada project personal E-Learning.

  • 7
    Test Management & Bug Tracking:

    Menggunakan Jira untuk mengelola Epic, Story, Task/Test Case, bug tracking, evidence, fix, dan retesting.

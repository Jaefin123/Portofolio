Gambaran Proyek & Tujuan

Context, technical problem statement, and solution architecture

Jaga Fakta.id merupakan aplikasi Android yang dibuat untuk membantu pengguna memeriksa informasi yang berpotensi hoaks atau disinformasi. Aplikasi menerima teks dari pengguna dan mengirimkannya ke backend untuk diproses oleh model klasifikasi IndoBERT yang telah di-fine-tune untuk deteksi hoaks.

Model AI tidak dijalankan langsung di dalam aplikasi Android. Aplikasi berperan sebagai client yang berkomunikasi dengan backend FastAPI. Backend memuat model dari Hugging Face, menjalankan proses inference, kemudian mengirimkan hasil klasifikasi kembali ke aplikasi.

Untuk membantu proses verifikasi, backend juga mengambil berita terkait melaluiTavily dari beberapa sumber berita dan menggunakan semantic similarity untuk memilih artikel yang paling relevan. Hasil klasifikasi model kemudian digabungkan dengan hasil retrieval sebelum sistem menentukan label HOAX atau VALID.

ARSITEKTUR SISTEM
  • ✓ Kotlin Android sebagai client
  • ✓ FastAPI sebagai backend AI
  • ✓ Fine-tuned IndoBERT dari Hugging Face
  • ✓ Tavily untuk retrieval berita terkait
  • ✓ Semantic similarity untuk pemilihan artikel
  • ✓ Hasil klasifikasi dikirim kembali melalui API

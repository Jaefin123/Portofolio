Jaga Fakta.id

Hoax Detection Mobile Application

Jaga Fakta.id is a mobile application designed to help the public quickly and accurately detect hoaxes and disinformation in Indonesian.

This app uses technology Natural Language Processing (NLP) based IndoBERT model to analyze text input from users, and use API backend FastAPI.

In this project, I played the role of:

  • Mobile Developer (Kotlin)
  • QA Engineer (Manual & Load Testing)
  • Integrasi API & Model AI

Tech Stack

Kotlin Android Studio FastAPI IndoBERT Firebase
